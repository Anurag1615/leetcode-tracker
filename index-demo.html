🔌 How to add pattern buttons to your nav

The four buttons above are .pattern-nav-btn elements. Each one links to a dedicated learning HTML page. The CSS for these buttons lives in backtracking.css so you only need one stylesheet across all pages.

On the page that is currently open, add class active-page to its button — this highlights it in orange so users know which page they're on.

In your index.html, just paste the nav buttons block into your existing .gnav-links div. No JS needed — they're plain anchor tags.
