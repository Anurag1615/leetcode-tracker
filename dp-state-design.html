🎛️ The Most Important DP Skill

Beginners struggle with DP not because the math is hard, but because they don't know what to put in dp[]. This module teaches you to derive the state definition from first principles — every time.

The 3 Questions to Find Your State
What changes between recursive calls?
The parameters that change = your state dimensions.
House Robber: only i (current index) changes → 1D state dp[i]
LCS: both i and j (positions in two strings) change → 2D state dp[i][j]
Stocks with k transactions: day, k, holding → 3D state dp[day][k][holding]
What affects future decisions?
Only include in state what is necessary to make the optimal decision going forward.
Knapsack: need remaining_capacity because it limits future choices.
House Robber: do NOT need "how I got here" — only current index matters.
Stock cooldown: need holding flag because you can't buy if you already hold.
What does dp[state] represent?
Write it in English. This IS your recurrence.
dp[i] = max money robbing from house i to end
dp[i][w] = max value using first i items with capacity w
dp[i][j] = LCS length of s1[0..i] and s2[0..j]

Worked Examples — Deriving State from Scratch
Coin Change — LC 322
Problem: min coins to make amount

Q1: What changes? → remaining amount (after picking a coin)
Q2: What affects future? → only rem matters — once I choose a coin, the remaining amount fully determines future options
Q3: dp[rem] = min coins to make exactly rem

// State: dp[rem] = min coins to make amount rem
int[] dp = new int[amount+1];
Arrays.fill(dp, amount+1);  // "infinity"
dp[0] = 0;                  // base: 0 coins to make 0

for (int rem = 1; rem <= amount; rem++)
    for (int coin : coins)
        if (coin <= rem)
            dp[rem] = Math.min(dp[rem], dp[rem-coin] + 1);
// Recurrence: dp[rem] = min over all coins of (dp[rem-coin] + 1)
// "Use 1 coin + solve smaller subproblem"
Stock with Cooldown — LC 309
Problem: max profit with 1-day cooldown after sell

Q1: What changes? → day and current state
Q2: What affects future? → whether I'm holding a stock, just sold, or in rest
Q3: Need 3 states: hold (max profit if holding), sold (just sold today), rest (in cooldown or idle)

// States: hold, sold, rest
// Transitions:
//   hold = max(hold, rest - price)   // keep holding OR buy (only from rest)
//   sold = hold + price              // sell today
//   rest = max(rest, sold)           // stay rest OR come from sold (cooldown)

int hold = Integer.MIN_VALUE, sold = 0, rest = 0;
for (int price : prices) {
    int prevSold = sold;
    sold = hold + price;              // sell: was holding
    hold = Math.max(hold, rest-price);// buy: was resting; or keep holding
    rest = Math.max(rest, prevSold);  // cooldown or stay idle
}
return Math.max(sold, rest);
LCS — LC 1143
Problem: longest common subsequence of two strings

Q1: What changes? → position i in s1 AND position j in s2
Q2: What affects future? → both indices — current position in each string determines what's available
Q3: dp[i][j] = LCS length of s1[0..i-1] and s2[0..j-1]

// State: dp[i][j] = LCS of s1[0..i-1] and s2[0..j-1]
int[][] dp = new int[m+1][n+1];

for (int i=1; i<=m; i++)
    for (int j=1; j<=n; j++)
        if (s1.charAt(i-1) == s2.charAt(j-1))
            dp[i][j] = dp[i-1][j-1] + 1;  // characters match → extend
        else
            dp[i][j] = Math.max(dp[i-1][j], dp[i][j-1]); // skip from either
0/1 Knapsack
Problem: max value with weight capacity W

Q1: What changes? → item index i (which items considered) AND remaining capacity w
Q2: What affects future? → both — we need to know which items remain AND how much capacity left
Q3: dp[i][w] = max value using first i items with capacity w

// State: dp[i][w] = max value, first i items, capacity w
// Recurrence:
//   skip item i: dp[i-1][w]
//   take item i (if fits): val[i] + dp[i-1][w-wt[i]]
//   dp[i][w] = max(skip, take)

// Space-optimised to 1D: dp[w] with REVERSE inner loop
int[] dp = new int[W+1];
for (int i=0; i<n; i++)
    for (int w=W; w>=wt[i]; w--)   // REVERSE = 0/1 (each item once)
        dp[w] = Math.max(dp[w], dp[w-wt[i]] + val[i]);
State Reduction — From 3D to 1D
💡 Always try to reduce dimensions

If dp[i] only depends on dp[i-1] → use two variables. If dp[i][j] only depends on row i-1 → use 1D rolling array. This is what separates good solutions from great ones.

OriginalReducedTrick
dp[n] Fibonaccia, b — O(1)Only need prev 2 values
dp[n][W] Knapsackdp[W] — O(W)Iterate weights in reverse
dp[m][n] LCSdp[n] with prev var — O(n)Row i only needs row i-1; save diagonal in prev
dp[n][k][2] Stocksbuy, sell arrays — O(k)At each day only 2 states per transaction count
