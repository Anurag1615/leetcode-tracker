📊 Tabulation

Bottom-Up DP. Fill a table iteratively from base cases. No recursion, no stack overflow, easy to space-optimise.

🔄 Memo → Tabulation: The 4-Step Recipe

Memoization is recursive (top-down). Tabulation is iterative (bottom-up). Same recurrence — different direction.
Step 1: Reverse the recursion direction
Step 2: Replace recursive calls with table lookups
Step 3: Seed base cases at the start
Step 4: Try to drop a dimension (space optimise)

Complete Conversion Examples
// House Robber — full progression

// 1. Memoization (top-down, O(n) space)
int robMemo(int[] nums, int i, int[] memo) {
    if (i >= nums.length) return 0;
    if (memo[i] != -1) return memo[i];
    return memo[i] = Math.max(nums[i]+robMemo(nums,i+2,memo), robMemo(nums,i+1,memo));
}

// 2. Tabulation (bottom-up, O(n) space)
int robTab(int[] nums) {
    int n = nums.length;
    if (n == 1) return nums[0];
    int[] dp = new int[n];
    dp[0] = nums[0];                           // base case
    dp[1] = Math.max(nums[0], nums[1]);        // base case
    for (int i = 2; i < n; i++)
        dp[i] = Math.max(dp[i-1], dp[i-2] + nums[i]); // recurrence
    return dp[n-1];
}

// 3. Space optimised (O(1) — dp[i] only needs dp[i-1] and dp[i-2])
int robOpt(int[] nums) {
    int prev2 = 0, prev1 = 0;
    for (int num : nums) {
        int curr = Math.max(prev1, prev2 + num);
        prev2 = prev1;
        prev1 = curr;
    }
    return prev1;
}
// Coin Change — LC 322

// Memo version (reference)
int solveMemo(int rem) {
    if (rem == 0) return 0;
    if (memo[rem] != -1) return memo[rem];
    int best = Integer.MAX_VALUE;
    for (int c : coins) if (c <= rem) {
        int sub = solveMemo(rem - c);
        if (sub != Integer.MAX_VALUE) best = Math.min(best, sub+1);
    }
    return memo[rem] = best;
}

// Tabulation version (bottom-up)
int coinChange(int[] coins, int amount) {
    int[] dp = new int[amount + 1];
    Arrays.fill(dp, amount + 1);               // "infinity" sentinel
    dp[0] = 0;                                 // base: 0 coins for amount 0
    for (int i = 1; i <= amount; i++)         // fill from 1 to amount
        for (int coin : coins)
            if (coin <= i)
                dp[i] = Math.min(dp[i], dp[i-coin] + 1); // same recurrence!
    return dp[amount] > amount ? -1 : dp[amount];
}
// dp[i-coin] replaces the recursive call solveMemo(rem-coin)
// LCS — LC 1143

// 1. Full 2D table — O(m×n) space
int lcs2D(String s1, String s2) {
    int m = s1.length(), n = s2.length();
    int[][] dp = new int[m+1][n+1];
    // base: dp[0][j]=0 and dp[i][0]=0 (already 0 by default)
    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++)
            if (s1.charAt(i-1) == s2.charAt(j-1))
                dp[i][j] = dp[i-1][j-1] + 1;   // match: diagonal + 1
            else
                dp[i][j] = Math.max(dp[i-1][j], dp[i][j-1]); // skip
    return dp[m][n];
}

// 2. Space optimised — O(n) rolling array
// dp[i] only needs dp[i-1] row AND diagonal value dp[i-1][j-1]
int lcs1D(String s1, String s2) {
    int m = s1.length(), n = s2.length();
    int[] dp = new int[n+1];
    for (int i = 1; i <= m; i++) {
        int prev = 0;                  // saves dp[i-1][j-1] (diagonal)
        for (int j = 1; j <= n; j++) {
            int temp = dp[j];
            if (s1.charAt(i-1) == s2.charAt(j-1))
                dp[j] = prev + 1;
            else
                dp[j] = Math.max(dp[j], dp[j-1]);
            prev = temp;               // next iteration's diagonal
        }
    }
    return dp[n];
}
// 0/1 Knapsack — full progression

// 1. 2D Tabulation — O(n×W) space
int knap2D(int[] wt, int[] val, int W) {
    int n = wt.length;
    int[][] dp = new int[n+1][W+1];
    for (int i = 1; i <= n; i++)
        for (int w = 1; w <= W; w++) {
            dp[i][w] = dp[i-1][w];             // skip item i
            if (wt[i-1] <= w)
                dp[i][w] = Math.max(dp[i][w],
                    dp[i-1][w-wt[i-1]] + val[i-1]); // take item i
        }
    return dp[n][W];
}

// 2. 1D Optimised — O(W) space
// CRITICAL: iterate W in REVERSE for 0/1 (each item once)
int knap1D(int[] wt, int[] val, int W) {
    int[] dp = new int[W+1];
    for (int i = 0; i < wt.length; i++)
        for (int w = W; w >= wt[i]; w--)  // REVERSE = 0/1
            dp[w] = Math.max(dp[w], dp[w-wt[i]] + val[i]);
    return dp[W];
}
// Change reverse→forward for Unbounded Knapsack (reuse allowed)

Fill Order — The One Thing Tabulation Requires
📐 Rule: When filling dp[i], all dp[j] that dp[i] depends on must already be filled

1D (left-to-right): dp[i] depends on dp[i-1], dp[i-2] → fill i from 0 to n ✅
2D (row by row): dp[i][j] depends on dp[i-1][j] and dp[i][j-1] → fill i then j ✅
Interval DP (by length): dp[i][j] depends on dp[i][k] and dp[k+1][j] where k<j → fill by increasing length ✅

If you fill in the wrong order, you read uncomputed values → wrong answers.
