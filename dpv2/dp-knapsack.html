🎒 0/1 Knapsack

Each item picked at most once. Include or exclude. The foundation of all DP.

📍 AV Playlist 1

⏱ Complexity

Time: O(n·W) · Space: O(W) after 1D optimisation

Core Code
int[] dp = new int[W+1];
for (int i = 0; i < n; i++)
    for (int w = W; w >= wt[i]; w--)  // REVERSE = 0/1
        dp[w] = Math.max(dp[w], dp[w-wt[i]] + val[i]);
return dp[W];
boolean[] dp = new boolean[target+1];
dp[0] = true;
for (int num : nums)
    for (int j = target; j >= num; j--)
        dp[j] |= dp[j-num];
return dp[target];
int[] dp = new int[target+1];
dp[0] = 1;
for (int num : nums)
    for (int j = target; j >= num; j--)
        dp[j] += dp[j-num];
return dp[target];
// Find subset with sum closest to total/2
boolean[] dp = new boolean[sum/2+1];
dp[0] = true;
for (int num : nums)
    for (int j = sum/2; j >= num; j--)
        dp[j] |= dp[j-num];
for (int j = sum/2; j >= 0; j--)
    if (dp[j]) return sum - 2*j;  // minimize |S1-S2|
return sum;
💡 Key Insight

Reverse inner loop = 0/1 (each item once). Forward = unbounded. This ONE rule separates the two.
