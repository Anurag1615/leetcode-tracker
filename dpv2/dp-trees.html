🌳 DP on Trees

Postorder processing. Return pair [include, exclude] from each subtree.

📍 AV Playlist 8

Postorder processing. Return pair [include, exclude] from each subtree.

⏱ Complexity

Time: O(n) · Space: O(h) recursion stack

Core Code
// Return [rob_this, skip_this] from each node
int[] dp(TreeNode node) {
    if (node == null) return new int[]{0, 0};
    int[] L = dp(node.left), R = dp(node.right);
    int rob  = node.val + L[1] + R[1]; // rob: skip children
    int skip = Math.max(L[0],L[1]) + Math.max(R[0],R[1]);
    return new int[]{rob, skip};
}
// Call: int[] r = dp(root); return Math.max(r[0], r[1]);
int ans = 0;
int depth(TreeNode node) {
    if (node == null) return 0;
    int L = depth(node.left), R = depth(node.right);
    ans = Math.max(ans, L + R); // path through this node
    return 1 + Math.max(L, R);
}
int ans = Integer.MIN_VALUE;
int gain(TreeNode node) {
    if (node == null) return 0;
    int L = Math.max(0, gain(node.left));  // ignore negative subtrees
    int R = Math.max(0, gain(node.right));
    ans = Math.max(ans, node.val + L + R); // path through node
    return node.val + Math.max(L, R);      // return single arm
}
💡 Key Insight

Key pattern: return PAIR (include/exclude) from each node. Parent combines children's best options. Never use a global "best path" without updating correctly at each node.
