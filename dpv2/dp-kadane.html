⚡ Kadane's Algorithm

Max subarray in O(n). Greedy restart when running sum goes negative.

📍 AV Playlist 6

Max subarray in O(n). Greedy restart when running sum goes negative.

⏱ Complexity

Time: O(n) · Space: O(1)

Core Code
int maxSubArray(int[] nums) {
    int maxSum = nums[0], curr = nums[0];
    for (int i = 1; i < nums.length; i++) {
        curr = Math.max(nums[i], curr + nums[i]); // restart or extend
        maxSum = Math.max(maxSum, curr);
    }
    return maxSum;
}
int maxProduct(int[] nums) {
    int maxP = nums[0], minP = nums[0], res = nums[0];
    for (int i = 1; i < nums.length; i++) {
        if (nums[i] < 0) { int t=maxP; maxP=minP; minP=t; } // flip on negative
        maxP = Math.max(nums[i], maxP * nums[i]);
        minP = Math.min(nums[i], minP * nums[i]);
        res  = Math.max(res, maxP);
    }
    return res;
}
int maxSumCircular(int[] nums) {
    int total=0, maxSum=nums[0], curMax=0,
        minSum=nums[0], curMin=0;
    for (int n : nums) {
        curMax = Math.max(curMax+n, n);
        maxSum = Math.max(maxSum, curMax);
        curMin = Math.min(curMin+n, n);
        minSum = Math.min(minSum, curMin);
        total += n;
    }
    // If all negative, maxSum is the answer
    return maxSum > 0 ? Math.max(maxSum, total-minSum) : maxSum;
}
💡 Key Insight

For circular: answer is max(normal Kadane, total − min subarray). If all numbers are negative, skip the circular case (total-minSum would be 0, which is wrong).
