🎯 The FAANG DP Reality

FAANG interviews rarely ask "implement Fibonacci DP." They ask problems where DP is one valid approach — you must recognise it, explain it, and justify your state definition. Communication is weighted as heavily as correctness. A correct solution poorly explained fails. A clean solution with clear thinking passes.

How to Present DP in an Interview — 4 Stages
Stage 1: Brute force first — always state it out loud
Say: "Let me start with the recursive brute force."
Write the recursion with hypothesis, induction, and base case.
Then explicitly say: "I can see that subproblem X is being recomputed — this suggests DP."
Interviewers want to see you recognize overlapping subproblems, not just jump to DP.
Stage 2: Identify the state — explain your dp[] definition
Say: "The state is dp[i][j] which represents [your English sentence]."
Justify why you need each dimension: "I need both i and j because [reason]."
This is where candidates lose points — mumbling through state design is a red flag.
Stage 3: Code the recurrence clearly
Write the recurrence as a comment first, then code it.
Name your variables descriptively: skip and take for knapsack, not a and b.
Handle edge cases before the main logic.
Stage 4: Mention space optimisation even if you don't code it
After getting the solution, proactively say:
"This is O(n²) space. I can reduce it to O(n) by using a rolling array since dp[i] only depends on dp[i-1]."
This shows depth and earns you brownie points.
6 Hard Problems Every Senior Candidate Must Know
🔥 LC 312 — Burst Balloons
Why hard
Must flip to "last burst" framing. Non-obvious state design.
Pattern
Interval DP — dp[i][j] = max coins in range [i,j]
Asked by
Google, Microsoft
🔥 LC 10 — Regular Expression Matching
Why hard
* matches zero or more of previous char. Tricky transitions.
Pattern
2D string DP — dp[i][j] = does s[0..i] match p[0..j]
Asked by
Google, Meta, Amazon
🔥 LC 188 — Best Time Stock IV
Why hard
Generalises to k transactions. Need to handle k >= n/2 edge case.
Pattern
State machine DP — dp[k][0/1]
Asked by
Goldman Sachs, quant firms
🔥 LC 354 — Russian Doll Envelopes
Why hard
Reduce 2D problem to 1D LIS. Sort trick: height DESC for equal widths.
Pattern
LIS — patience sort O(n log n)
Asked by
Amazon, Meta
🔥 LC 72 — Edit Distance
Why hard
Three operations. Must enumerate all transitions carefully.
Pattern
LCS variant — dp[i][j] = min edits for s[0..i], t[0..j]
Asked by
Google, Meta, Amazon, Microsoft
🔥 LC 1335 — Minimum Difficulty Job Schedule
Why hard
Combines partition DP with prefix maximums. Clean state design needed.
Pattern
Interval/partition DP — dp[day][i]
Asked by
Google, Amazon

✅ The one thing separating FAANG from average

After every DP solution, immediately ask: "Can I reduce the space complexity?"
O(n²) → O(n) → O(1) progression is expected at senior level.
And always be ready to explain the recurrence in plain English before writing code. The 45-minute interview clock is against you — being able to talk through DP quickly matters as much as coding it.
