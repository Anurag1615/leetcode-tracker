♾️ Unbounded Knapsack

Same item usable unlimited times. Rod Cutting, Coin Change, Ribbon.

📍 AV Playlist 2

Same item usable unlimited times. Rod Cutting, Coin Change, Ribbon.

⏱ Complexity

Time: O(n·W) · Space: O(W)

Core Code
int[] dp = new int[W+1];
for (int i = 0; i < n; i++)
    for (int w = wt[i]; w <= W; w++)  // FORWARD = unbounded
        dp[w] = Math.max(dp[w], dp[w-wt[i]] + val[i]);
return dp[W];
// Min coins
int[] dp = new int[amount+1];
Arrays.fill(dp, amount+1);
dp[0] = 0;
for (int coin : coins)
    for (int j = coin; j <= amount; j++)
        dp[j] = Math.min(dp[j], dp[j-coin]+1);
return dp[amount] > amount ? -1 : dp[amount];
// Count ways (combinations)
long[] dp = new long[amount+1];
dp[0] = 1;
for (int coin : coins)        // coins OUTER = combinations
    for (int j = coin; j <= amount; j++)
        dp[j] += dp[j-coin];
return dp[amount];
// Count ordered ways (permutations)
int[] dp = new int[target+1];
dp[0] = 1;
for (int j = 1; j <= target; j++)  // amounts OUTER = permutations
    for (int coin : coins)
        if (j >= coin) dp[j] += dp[j-coin];
return dp[target];
💡 Key Insight

Coins outer loop → unordered combinations. Amounts outer loop → ordered permutations. This is LC 518 vs LC 377.
